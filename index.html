สำหรับนักวิชาการสาธารณสุข - 3 ขั้นตอนง่ายๆ

1

สร้างไฟล์ index.html

บันทึกซอร์สโค้ดในหน้านี้เป็นชื่อไฟล์ว่า index.html ลงในคอมพิวเตอร์ของคุณ

2

อัพโหลดขึ้น GitHub Repository

เข้าสู่เว็บไซต์ GitHub.com > สร้าง Repository ใหม่ (ตั้งชื่อเช่น public-health-dashboard) เลือกเปิดแบบ Public แล้วอัพโหลดไฟล์ index.html ขึ้นไป

3

เปิดใช้งาน GitHub Pages

ไปที่เมนู Settings ของ Repository > เลือก Pages ทางซ้ายมือ > ในหัวข้อ Build and deployment ตรง Branch ให้เลือก main หรือ master แล้วกด Save

เสร็จสิ้น! คุณจะได้ URL เว็บไซต์สาธารณะ เช่น https://yourusername.github.io/public-health-dashboard/ สามารถส่งต่อให้ทีมงานและผู้บริหารเข้าดูได้ทันที
